Настройки

Telegram-бот

Создай отдельного бота через @BotFather. Один токен должен использоваться только этим сервисом.

Токен хранится только на сервере.

После сохранения отправь боту /start со своего аккаунта. Другие пользователи и групповые чаты игнорируются.

Доступ к GitHub

Токен нужен для приватных репозиториев и более частых проверок. Для выбранных репозиториев достаточно разрешения Contents: Read-only.

Публичные репозитории доступны без токена.
